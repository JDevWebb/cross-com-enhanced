A test build of Cross-Com Enhanced, free community servers for *Tom Clancy's Ghost Recon: Future Soldier*'s online play. This one brings a redesigned launcher, matches that start with as few as two players, and squad matches. It's still for public testing: expect rough edges, and expect accounts and stats to be reset before a later build. **Your reports are what this build is for.**

If you have 0.1.1, the launcher offers this update in the bar under its title.

## What's new

**A redesigned launcher**
- **The setup shows once**, the first time you run the launcher. After that, everything it set is in **Settings**, one section at a time: Game, Server, Identity, Network, Logs and About. Changes are saved as you make them.
- **Settings › Server** switches server without going through the setup again. **Settings › Game** changes the game's folder.
- **Play** is laid out like its sister launcher's. It shows the game's name, your name and identity, and the server beside a larger Play button. A side panel shows the status (the server, the client, the firewall, port forwarding and your last game's connection) and the server's news.
- **A status bar** along the bottom of the window says how things stand: signed in, the game starting, logs being sent, or what went wrong.
- **About** is the last section of Settings, with **Run the setup again** if you ever want to start over. The setup changes nothing until its last step.
- **The window fits smaller screens** (a laptop at 150 % or 200 % scaling) instead of opening under the taskbar.

**Matches start with two players**
- A Quick Match starts with 2 players or more, not the game's own 8, so a quiet server still gets matches. **Settings › Game › Fewest players to start a match** changes it (2 to 12). A lobby's host can still change it for that lobby in the overlay's Lobby tab.

**Squad matches**
- **Play Squad Quick Match** works. Your squad's leader opens a party, squadmates join it from the **Squad Parties** list (which now shows who's in each party), and **Join Game** finds another squad to play. They start with half the fewest-players setting a side, so one a side by default. The game asks for four a side otherwise.
- Squad wins, losses and XP are kept on the server, and your squad's level grows with them.

**Server**
- Squad parties and squad matchmaking (see above).
- A server on your own network hands players each other's addresses on that network, so players and the server can all share one network without anything clashing. Tested with three players.

## Play

1. Download **`crosscom-launcher.exe`** below. It's the only file you need: the client is built in. Keep it in a folder of your own (your Desktop or Documents, not Program Files), so it can update itself.
2. Run it. The setup finds the game, lets it through Windows Firewall (one Windows permission prompt), makes your account on the community test network, `grfs-test.jdevwebb.net` (you choose a name: there's no password), and installs the client into the game, keeping the game's own files.
3. Press **Play**.

You need your own copy of the game, and of any DLC pack you want to play: nothing of the game is included, and we can't help you get it. More in the [README](https://github.com/JDevWebb/cross-com-enhanced#play).

## Run your own server

The server is one program, for Linux, in Docker with HTTPS through Caddy, or on its own: see [Hosting](https://github.com/JDevWebb/cross-com-enhanced/blob/main/docs/hosting.md). Its image for this release is `ghcr.io/jdevwebb/crosscom-server:0.1.2`, signed with the release (`IMAGE`, `IMAGE.sig`). Upgrade the server with the launcher: squad parties and squad matches need both.

## Good to know

- **Squad matches have been played one a side**, on a server on its own network. Bigger squads should work the same way; tell us how it goes.
- **Voice chat hasn't been tested yet.** It needs real microphones.
- **Some players can't reach each other directly** when both their routers are strict, or behind their provider's shared address. The overlay's Server tab and **Settings › Network** tell you how reachable you are. A relay for those players is planned for 0.2.0.
- **Microsoft Defender may remove the launcher as soon as it's downloaded** (`Trojan:Win32/Bearfoos.B!ml`, a machine-learning guess). It's a false positive: the files aren't code-signed yet. Restore it from **Windows Security › Protection history**, check it against the verification details below before you run it, and exclude its folder and the game's: step by step in [Antivirus warnings](https://github.com/JDevWebb/cross-com-enhanced#antivirus-warnings).
- **Found a problem?** Open an issue with what happened and roughly when. A security problem goes through the Security tab instead: see [SECURITY.md](https://github.com/JDevWebb/cross-com-enhanced/blob/main/SECURITY.md).
